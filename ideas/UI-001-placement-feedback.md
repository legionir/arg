# UI-001: بازخورد دلیل رد ساخت + پنل منابع

- دسته اصلی: User Experience / Interface
- برچسب تخصصی: UI, CONST, ECON
- وضعیت: completed (منتشرشده در 0.7.0 — هر ۴ معیار qa-plan پاس؛ C-UI-1 با ۵ موقعیت زنده روی صفحه بازبینی شد؛ C-REL-1..4 پاس)
- اندازه: S
- ارزش / اولویت: زیاد — هزینه کم، اثر بزرگ: بازیکنِ سردرگم بازی را رها می‌کند
- برجسته ★: خیر (کوچک ولی مهم)
> برش اول (اکتبر ۲۰۲۶): گوست سبز/قرمز + دلیل رد فارسی + پنل ۳ منبعی، تست‌شده (دسکتاپ و موبایل).

## وضعیت فعلی
هیچ UI ساخت یا پنل منابعی وجود ندارد.

## مسئله / فرصت
اگر ساخت فقط «بله/خیر» بگوید، بازیکن دلیل رد (زمین؟ اشغال؟ هم‌پوشانی؟) را نمی‌فهمد و تصور باگ می‌کند. جدا از آن، بدون پنل زنده منابع، اثر `ECON-001` نامرئی است.

## تغییر پیشنهادی
(۱) نمایش دلیل رد از `CONST-001` در محل نشانگر (متن کوتاه + رنگ)؛ (۲) پنل منابع زنده (مقادیر + نرخ خالص هر منبع) که از مدل اقتصاد می‌خواند، نه از منطق جدا.

## نتیجه مورد انتظار
در تست دستی ۵ موقعیت نامعتبر، هر ۵ بار دلیل نمایش‌داده‌شده با دلیل واقعی اعتبارسنج یکی باشد؛ موجودی پنل با مدل اقتصاد همگام بماند (بدون رفرش دستی).

## رفتار مورد انتظار
- پیش‌نمایش ساخت (ghost) سبز/قرمز + برچسب دلیل باشد.
- پنل منابع فقط خواندنی باشد (هیچ منطقی در UI تغییر وضعیت ندهد — جدایی منطق از نمایش).
- پیام خطا با شناسه قابل تست باشد (نه فقط رنگ).

## وابستگی‌ها
- نیاز دارد: خروجی دلیل‌دار از `CONST-001`، خواندن مدل `ECON-001`.
- اثر می‌گذارد بر: هیچ منطقی — فقط نمایش (اثر معماری عمداً صفر نگه داشته شود).

## فرضیات / مجهولات
- سبک بصری نهایی (فونت، آیکون) نامشخص — فعلاً متن ساده کافی است.
- چیدمان موبایل/دسکتاپ نامشخص — فعلاً دسکتاپ اول.

## اولین گام پیشنهادی
- لیست ۴ دلیل رد (زمین، اشغال، هم‌پوشانی، قانون خاص) با کد ثابت + پنل متنی ۴ منبعی که هر تیک به‌روز شود.

## چک‌لیست باقی‌مانده تا implemented (استخراج اکتبر ۲۰۲۶)

- [x] گوست سبز/قرمز + دلیل رد فارسی (`REASON_FA`) + پنل ۳ منبعی زنده — پیاده و در دسکتاپ/موبایل دستی تست‌شده.
- [ ] سبک بصری نهایی (فونت/آیکون) عمداً معوق است — جزو دامنه نسخه اول نیست؛ ثبت شد تا گم نشود.

## شاهد تأیید (اکتبر ۲۰۲۶، صفحه زنده)

- آب (۲۲،۲۱) → `TERRAIN` → نمایش «زمین نامناسب (آب/سنگ)» ✓
- هم‌پوشانی با لنگر آزاد (۴،۴ روی کلبه ۵،۵) → `OCCUPIED` → نمایش «اشغال‌شده» ✓
- روی ساختمان → اطلاعات ساختمان (رفتار طراحی‌شده، نه دلیل رد) ✓
- خارج نقشه → `OUT_OF_BOUNDS` → نمایش «خارج از نقشه» ✓
- معتبر (۷،۱) → `OK` → نمایش «معتبر» ✓
- نمایش در هر ۵ مورد با دلیل واقعی اعتبارسنج یکی بود → `verified`.
